# Meus Exercícios do Exercism

## 🚀 Sobre o Projeto

Bem-vindo ao meu repositório de soluções do [Exercism.org](https://exercism.org)!

Este projeto é um espaço pessoal onde eu guardo e organizo todas as minhas soluções para os desafios de programação que completo na plataforma. O objetivo principal é documentar meu progresso de aprendizado, praticar diferentes linguagens e ter um registro das minhas soluções para referência futura.

Atualmente, estou focando na trilha de **Elixir**.

## 📂 Estrutura do Repositório

O repositório está organizado de forma simples:

- Cada diretório de primeiro nível corresponde a um exercício específico.
- Dentro de cada exercício, você encontrará a estrutura de um projeto padrão da linguagem em questão.
- O código da minha solução fica geralmente no diretório `lib/`.

As soluções são enviadas para este repositório diretamente pela [CLI do Exercism](https://exercism.org/docs/using/cli/submitting-your-code).
